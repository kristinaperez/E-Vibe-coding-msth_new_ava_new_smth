# Аватарки «Выделяйся» — kristinaperez/E-Vibe-coding-msth_new_ava_new_smth

Бесплатный сайт на Vercel: человек загружает фото и получает аватарку в едином стиле для соцсетей, которую узнают во всех сетях. Проект — рабочий инструмент и часть продукта Кристины: через него она продвигает свои проекты и реферальные ссылки.

## Что делает продукт
1. Загрузка фото → кадрирование в круг.
2. Надпись-настроение + подсвеченный запрос + цвет.
3. **Рамки** (идея из файла «Продуктового подхода»): нестандартные рамки для аватарок, как OpenToWork или Hiring, но с любым текстом человека, цветом и векторным символом. Рамка одинаково выглядит в круге и в квадрате. Подбор хэштега и оттенка — под стиль и настроение человека. Рамка подсвечивает запрос и выделяет профиль в ленте.
4. Экспорт аватарок: Threads, ВКонтакте, Макс, LinkedIn, Facebook, Instagram.
5. Threads-версия: кольцо вокруг аватарки и call to action. Гипотеза: надпись видна только при открытии аватарки. **Не подтверждено**: Кристина проверит на своём аккаунте сама. До проверки не обещать это клиентам как факт.
6. **LinkedIn — первая платформа.** Есть референсы и примеры, их показывать людям при выборе стиля.
7. Подарки (только если человек делится своими соцсетями и делает хотя бы одну аватарку): фоны для Zoom и Google Meet, гайд по стилю, топовый прообраз.
8. Раздел баннеров для бизнеса — **в разработке**, в интерфейсе только заглушка.

Фото обрабатываются в браузере (canvas), на сервер не уходят.

## CTA по умолчанию (для Threads)
«Попробуйте наш новый сервис. Проект «Выделяйся»». Текст редактируемый: человек может вписать свой.

## Стек и структура
- Статичный сайт: один `index.html` (HTML/CSS/JS без сборки), деплой на Vercel.
- Без серверной части в первой версии.

```
index.html   — интерфейс и логика canvas
README.md    — как открыть локально и задеплоить
```

## Команды
- Локально: открыть `index.html` в браузере (или `npx serve .`).
- Деплой: Vercel, статичный проект из корня репозитория.

## Правила работы Клода в этом репо
- Коммиты, push и PR можно делать самостоятельно.
- **Деплой на прод — только после ревью отдельным субагентом** (reviewer на модели Sonnet). Ревью нужно перед деплоем на прод, не на каждый коммит. Живой сайт не должен ломаться.
- В ответах с кодом — только diff/изменённые куски, без пересказа всего файла и без объяснений (если не попросили).
- Тексты для интерфейса и CTA — по-русски. Название продукта: «Выделяйся».
- Не сохранять и не логировать загруженные фото.
- Баннеры не делать, пока Кристина не даст требования (нужно больше данных о человеке).
- Ноу-хау Threads (круг + скрытая надпись) не заявлять как проверенное, пока Кристина не проверит.
