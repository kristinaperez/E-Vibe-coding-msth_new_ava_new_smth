# Аватарки «Выделяйся» — kristinaperez/E-Vibe-coding-msth_new_ava_new_smth

Бесплатный сайт на Vercel: человек загружает фото и получает аватарку в едином стиле для соцсетей, которую узнают во всех сетях. Проект — рабочий инструмент и часть продукта Кристины: через него она продвигает свои проекты и реферальные ссылки.

## Что делает продукт
1. Загрузка фото → кадрирование в круг.
2. Надпись-настроение + подсвеченный запрос + цвет.
3. **Рамки** (идея из файла «Продуктового подхода»): нестандартные рамки для аватарок, как OpenToWork или Hiring, но с любым текстом человека, цветом и векторным символом. Рамка одинаково выглядит в круге и в квадрате. Подбор хэштега и оттенка — под стиль и настроение человека. Рамка подсвечивает запрос и выделяет профиль в ленте.
4. Экспорт аватарок: Threads, ВКонтакте, Макс, LinkedIn, Facebook, Instagram.
5. Threads-версия: кольцо вокруг аватарки и call to action. Гипотеза: надпись видна только при открытии аватарки. **Не подтверждено**: Кристина проверит на своём аккаунте сама. До проверки не обещать это клиентам как факт.
6. **Первая платформа — Threads** (сейчас самая продвигаемая сеть, аудитория Кристины там). LinkedIn — следующая, с собственными референсами.
7. Подарки (только если человек делится своими соцсетями и делает хотя бы одну аватарку): фоны для Zoom и Google Meet, гайд по стилю, топовый прообраз.
8. Раздел баннеров для бизнеса — **в разработке**, в интерфейсе только заглушка.

Фото обрабатываются в браузере (canvas), на сервер не уходят.

## Референсы Threads (папка «Примеры АВЫ Тредс»)
- Аниме-персонаж на весь круг, без текста.
- Девушка на розовом фоне со стикерами-«мыслями» (E=mc², сумка), без текста.
- Девушка с толстым магента-кольцом, без текста.
- Мозаичное солнце — арт, не человек, узнаваемости нет.
- Вывод: все популярные варианты — визуал без текста. Кольцо — общий приём. Текст на аватарке в ленте не читается (аватарка маленькая), поэтому идея открываемой надписи. Это гипотеза, её проверяет Кристина.

## Подарки (только при условии: сделан хотя бы один аватар + передана ссылка на соцсеть)
1. Фоны для Zoom и Google Meet (два файла 1920×1080). Вдобавок к остальным.
2. **Мини-статья в Telegraph** о мастере (за первый обработанный ролик через реферальную ссылку). Вдобавок к фонам. Кнопка «Отправить» в Telegram: требует Telegram-аккаунт человека, без него не отправляем. Публикацию показываем человеку до выхода, согласие обязательно.
3. **Гайд по стилю** (`content/style-guide.md`). Прообраз — текстовое описание стиля, подбирается по анкете, добровольно.

### Результат теста «Уникализатора» (2026-11-05)
- Бот **не заменяет фон**. Домашний фон остался виден.
- Размытие фона сделали отдельно, в другом инструменте (по словам Кристины — ChatGPT). Название инструмента в публичных текстах указывать точно.
- Бот вернул смонтированный ролик с субтитрами, звук сохранился.
- Возможная услуга: размыть фон в готовом MP4. Запуск и доступность (всем или только по рефералке) пока не решены, в код не закладываем.
- Вся прежняя формулировка про «поменять фон через бота» и рефералку за замену фона **не использовать**.
- Слово «партнёрский» не употреблять, пока нет договорённости с командой бота. Писать «мой реферальный бот».
- Видео мастеров отправлять сторонним сервисам только с согласия мастера.

Правила для подарков:
- Фото реальных людей (в том числе знаменитостей) в гайд и на сайт не включаем.
- Не генерируем «улучшенное» лицо или тело пользователя (AI-правка внешности). Прообраз только текстовый.
- Не описываем и не обсуждаем внешность людей с созвонов и из эфиров. Истории с конкретными людьми на сайте не публикуем.
- Гайд не содержит комментариев о теле и фигуре (вес, размер груди, «полная» или «выраженная» фигура и т. п.). Подбор — по вещи и посадке, не по телу.
- Референсы знаменитостей (фото, ссылки, заметки о приёмах) не храним в репозитории: он может быть публичным. Внутренние заметки ведём отдельно, вне кода. Ссылки на статьи проверяем: часть ссылок из черновика не открылась или заголовок не про стиль (например, про похудение).
- Визуальная примерка — только по фото клиентки, с её явным согласием. Фото, загруженное для аватарки, для примерки использовать только после отдельного согласия. Меняются только одежда и причёска по её просьбе.
- Список прообразов для гайда пока не передан Кристиной: в гайде стоит заглушка.
- Кнопка «Отправить» в Telegram: серверная функция на Vercel (разрешено Кристиной). Бот — Морок, токен в Vercel как `MOROK_BOT_TOKEN` (Production), в код и репозиторий не попадает.
- Морок только отправляет сообщения (`sendMessage`). **Вебхук не настраивать**: он уже стоит для хэллоуинского бота (`halloween_bot`, активен до 2026-11-08), и новая настройка его сломает.
- Бот не может написать человеку, пока тот не нажал /start у Морока. На сайте рядом с кнопкой «Отправить» написать об этом.

## CTA по умолчанию (для Threads)
«Попробуйте наш новый сервис. Проект «Выделяйся»». Текст редактируемый: человек может вписать свой.

## Стек и структура
- Статичный сайт: один `index.html` (HTML/CSS/JS без сборки), деплой на Vercel.
- Серверная часть — только для отправки подарков в Telegram (serverless-функция на Vercel, см. «Подарки»). Остальной сайт остаётся без сервера.

```
index.html   — интерфейс и логика canvas
README.md    — как открыть локально и задеплоить
```

## Команды
- Локально: открыть `index.html` в браузере (или `npx serve .`).
- Деплой: Vercel, статичный проект из корня репозитория.

## Правила работы Клода в этом репо
- Коммиты, push и PR можно делать самостоятельно.
- **Деплой на прод — только после ревью отдельным субагентом** (reviewer на модели Sonnet). Ревью нужно перед деплоем на прод, не на каждый коммит. Живой сайт не должен ломаться.
- В ответах с кодом — только diff/изменённые куски, без пересказа всего файла и без объяснений (если не попросили).
- Тексты для интерфейса и CTA — по-русски. Название продукта: «Выделяйся».
- Не сохранять и не логировать загруженные фото.
- Баннеры не делать, пока Кристина не даст требования (нужно больше данных о человеке).
- Ноу-хау Threads (круг + скрытая надпись) не заявлять как проверенное, пока Кристина не проверит.
